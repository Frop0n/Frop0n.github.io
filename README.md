# Pagina Web de mi Empresa

Bienvenido a el sitio web de mi Empresa!. Este repositorio contiene el código fuente de la pagina web de mi empresa Bolsillo SpA, donde prestamos servicios como agencia de Marketing y Identidad Digital para empresas.

## 🛠️ Tecnologías Utilizadas

- **HTML5** - Estructura semántica
- **CSS3** - Estilos y diseño responsivo
- **JavaScript** - Interactividad y funcionalidad dinámica
- **Diseño Responsivo** - Compatible con dispositivos móviles y de escritorio

## 📁 Estructura del Proyecto

```
.
├── index.html          # Página principal
├── style.css           # Estilos principales
├── script.js           # Lógica de JavaScript
├── components/         # Componentes reutilizables
├── images/             # Recursos gráficos
└── README.md           # Este archivo
```

## 🌐 Características

- Diseño moderno y limpio
- Navegación intuitiva
- Sección de proyectos destacados
- Información sobre servicios ofrecidos
- Formulario de contacto
- Optimizado para SEO
